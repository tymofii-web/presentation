# FreshWater — GitHub Pages presentation

A responsive, 16-slide browser presentation for the FreshWater smart bottle concept. It uses local photo assets, works without a JavaScript framework, and can be hosted with GitHub Pages.

## Preview on your computer
1. Download and unzip this folder.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Use the **left/right arrows** or **Space** to move between slides.
4. Press **F** for fullscreen and **P** to print / save as PDF.

Keep the `assets` folder next to `index.html`; the page needs those images to display correctly.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `freshwater-presentation`.
2. Upload `index.html`, the `assets` folder, and this `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then press **Save**.
6. Wait for GitHub to show the published site URL in the Pages section.

## Presentation controls
- `←` / `→` or `PageUp` / `PageDown`: previous/next slide
- `Space`: next slide
- `Home` / `End`: first/last slide
- `F`: toggle fullscreen
- `P`: print or save to PDF
- On mobile, swipe left/right to navigate

## Important cost and science notes
- One-off prototype parts are estimated at about **CAD $90–$120**, before tax and shipping. The breakdown in the presentation totals about CAD $107 using example retail parts and planning allowances.
- **CAD $8 per bottle** is the ambitious target for a simplified, custom-designed product manufactured in high volume. It is not a verified factory quote and is not achievable with the current retail-module prototype as shown without major redesign and lower-cost sourcing.
- Planned selling prices: **CAD $19.99 launch offer**, **CAD $24.99 everyday price**, and a possible price up to **CAD $26.99** for one bottle.
- A **4-bottle family pack is CAD $59.99**. If the $8 target cost is achieved, the target gross profit is $11.99 for a $19.99 bottle, $16.99 for a $24.99 bottle, $18.99 for a $26.99 bottle, and $27.99 for the 4-bottle family pack. Gross profit is before marketing, shipping, fees, tax, returns, warranty, research, and salaries.
- The sensor concept can only check selected signals such as turbidity/cloudiness and temperature. It cannot detect all bacteria, viruses, chemicals, or contaminants, and a green light must not be described as proof that water is safe to drink.
- Product photos and technical images are concept mock-ups, not photographs of a certified production product.
